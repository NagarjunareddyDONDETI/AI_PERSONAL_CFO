## 📖 Overview

**AI Personal CFO** is an enterprise-grade, full-stack financial intelligence platform designed to replace conventional, passive budgeting apps with an **autonomous committee of specialized AI financial agents**.

By combining **LangGraph multi-agent consensus workflows**, **ChromaDB vector retrieval (RAG)**, **3D spatial embedding visualization with Three.js**, and a **real-time voice financial advisor ("Finzo")**, the platform delivers institutional-grade wealth planning, tax-advantaged strategy, risk mitigation, and probabilistic forecasting directly to individuals.

## ✨ Key Features

### 1. 🤖 Multi-Agent Financial Committee (LangGraph)
Instead of relying on a single prompt, user decisions undergo a structured debate between specialized AI persona agents:
- **🛡️ Risk Auditor Agent**: Stress-tests decisions against emergency reserves, debt ratios, and black-swan market downturns.
- **📈 Growth Strategist Agent**: Calculates opportunity cost, asset allocation, and aggressive compounding potential.
- **⚖️ Tax & Cashflow Specialist**: Analyzes tax efficiency, deduction opportunities, and liquidity constraints.
- **🎯 Chief Decider (CFO)**: Evaluates agent arguments, balances conflicting tradeoffs, and produces a final synthesis with confidence ratings.

### 2. 🎙️ "Finzo" Voice Financial Assistant
- **Hands-Free Speech Interaction**: Real-time voice Q&A powered by Groq Whisper STT and natural TTS speech synthesis.
- **Context-Aware Memory**: Retains user financial context across sessions to answer questions like *"How much can I spend on dining out this weekend while staying on track for my house down payment?"*

### 3. 🔮 3D Spatial RAG Visualizer (ChromaDB + Three.js)
- **Vector Space Exploration**: Inspect how queries and knowledge chunks interact in real-time.
- **Interactive PCA Projections**: Visualizes 384-dimensional `all-MiniLM-L6-v2` embeddings projected into an interactive 3D spatial orbit.

### 4. 📊 Digital Financial Twin & What-If Simulations
- **Monte Carlo Projections**: Simulate 10-year probabilistic net worth trajectories under Bull, Baseline, and Bear economic regimes.
- **Instant Scenario Sandbox**: Model major life events (career change, buying property, sabbatical) and quantify their impact before taking action.

### 5. 🔒 Enterprise Security & Scalability
- **Zero-Storage Secrets**: Robust provider abstraction for OpenAI, Claude, Groq, Gemini, and local models.
- **SQLite WAL Mode**: Thread-safe, low-latency persistent data store.
- **JWT & Rate Limiting**: Secure token authentication with built-in route protection.

## 🚀 Getting Started Locally

### Prerequisites
- **Node.js**: v18.0+ or v20.0+
- **Python**: v3.11+ or v3.12+
- **Git**

### 1. Clone the Repository
```bash
git clone https://github.com/NagarjunareddyDONDETI/AI_PERSONAL_CFO.git
cd AI_PERSONAL_CFO
```

---

### 2. Backend Setup
```bash
# Navigate to backend directory
cd backend

# Create & activate virtual environment
python -m venv .venv

# On Windows:
.venv\Scripts\activate
# On Linux/macOS:
source .venv/bin/activate

# Install dependencies
pip install -r requirements.txt

# Start FastAPI development server
uvicorn main:app --reload --host 0.0.0.0 --port 8000
```
*Backend API will be accessible at: `http://localhost:8000` (Swagger UI at `/docs`)*

---

### 3. Frontend Setup
```bash
# Open a new terminal and navigate to frontend directory
cd frontend

# Install npm dependencies
npm install

# Start Vite development server
npm run dev
```
*Frontend will be running at: `http://localhost:5173`*

## 🔄 CI/CD & Deployment Pipeline

This repository is configured with an automated GitHub Actions CI/CD workflow located at [`.github/workflows/deploy.yml`](.github/workflows/deploy.yml):

- **Automated Validation on Push / PR**: Runs Python 3.12 pytest suite and frontend TypeScript/Vite compilation.
- **Continuous Deployment to Render**: Triggers instant zero-downtime rolling deploys upon merging to `main`.
- **Post-Deploy Smoke Testing**: Verifies live endpoint health and availability automatically.
